// Flows
User > Amplify: open dashboard
User > ApiGateway: HTTPS /api/*

Edge > Iot: MQTT pub/sub (JSON)
Iot > Fog: subscribe sensors/*
Fog > ApiGateway: POST readings

ApiGateway > Lambda: invoke
Lambda <> Database: store & read sensor data
